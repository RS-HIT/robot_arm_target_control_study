# 轨迹规划学习笔记

## 1. 位置轨迹

位置轨迹是一串希望机械臂经过的位置点。

在关节空间中，位置轨迹是：

```text
theta1, theta2
```

在笛卡尔空间中，位置轨迹是：

```text
x, y
```

## 2. 速度轨迹

速度轨迹描述位置变化得多快。

对关节来说，速度是关节角速度，例如 `rad/s`。对末端来说，速度是末端在 `x/y` 平面中的移动速度。

## 3. 加速度轨迹

加速度轨迹描述速度变化得多快。

如果加速度曲线有尖峰，说明动作突然变化。真实机械臂上，这可能意味着电机需要瞬间输出很大的力矩。

## 4. 为什么真实机械臂不能只给位置点

如果只给一串位置点，机械臂不知道应该多快到达，也不知道中间运动是否平滑。

真实系统通常还要考虑：

- 最大速度。
- 最大加速度。
- 电机能力。
- 结构安全。
- 动作是否平滑。

## 5. 什么是轨迹平滑性

轨迹平滑性可以从三个层面理解：

- 位置连续：不要突然跳到另一个位置。
- 速度连续：不要突然从静止变成很快。
- 加速度较平滑：不要突然猛加速或猛刹车。

`linear` 插值位置连续，但起终点速度不够自然。

`cubic` 能让起终点速度为 0。

`quintic` 进一步让起终点加速度也更平滑。

## 6. 如何从曲线判断轨迹是否适合执行

可以看：

- 位置曲线是否连续。
- 速度曲线是否有尖峰。
- 加速度曲线是否剧烈抖动。
- 最大速度是否过大。
- 最大加速度是否过大。
- RMS 加速度是否整体偏大。

如果速度和加速度曲线都比较平滑，通常说明轨迹更适合机械臂执行。

## 7. 本项目目前仍然没有引入动力学和电机控制

本项目第五阶段仍然是运动学层面的学习项目。

它没有考虑：

- 连杆质量。
- 惯量矩阵。
- 重力补偿。
- 摩擦。
- 电机力矩限制。
- 真实控制周期延迟。

所以当前的速度和加速度分析用于建立直觉，不等价于完整机器人动力学仿真。
