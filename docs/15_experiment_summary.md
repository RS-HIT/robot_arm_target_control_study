# 实验结论汇总

这份文档把当前项目中比较重要的实验现象整理成“现象 -> 解释 -> 项目结论”的形式。当前结论只来自 2D 二连杆机械臂的运动学实验，不能直接等同于完整动力学仿真或真实机械臂验证。

## 1. 目标点控制实验

实验现象：给定一个可达目标点后，雅可比伪逆控制可以通过多次迭代让末端逐步靠近目标点。误差曲线通常会下降，关节角曲线会记录两个关节如何配合运动。

解释：每一步控制都先计算“末端当前位置到目标点的误差”，再用雅可比伪逆把这个末端误差转换成关节角的小更新。`gain` 决定更新力度，`max_step` 限制单步最大关节变化，`tolerance` 决定误差小到什么程度算到达。

项目结论：目标点控制不能只看 `final_error`。如果只看最后误差，可能忽略中间是否震荡、是否过慢、关节角是否突然跳变。更完整的判断应该同时看误差曲线和关节角曲线。

## 2. 解析逆运动学 vs 雅可比迭代

实验现象：对于 2D 二连杆机械臂，解析逆运动学可以直接给出一组关节角；雅可比迭代则从初始姿态出发，一步一步逼近目标点。

解释：解析法利用二连杆的几何关系求解，适合结构简单、公式清楚的机械臂。雅可比迭代不依赖特定几何闭式解，更接近通用数值控制思想，但会受到初始姿态、步长、阻尼和奇异位形影响。

项目结论：解析法更直接，适合用来理解“目标点如何对应关节角”；迭代法更通用，适合继续扩展到更高自由度机械臂的控制思路。

## 3. 阻尼伪逆与奇异位形

实验现象：机械臂接近伸直等奇异位形时，普通雅可比伪逆可能产生较大的关节更新，关节角曲线更容易出现突然变化。加入阻尼后，更新通常更保守、更平滑。

解释：奇异位形附近，某些末端运动方向很难通过关节小变化实现，普通伪逆的数值结果容易被放大。阻尼最小二乘在计算中加入 `damping`，相当于给过大的更新加了约束。

项目结论：阻尼可以提高数值稳定性，但不是越大越好。`damping` 太小会接近普通伪逆，太大则可能让动作过于保守，导致收敛变慢或误差下降不充分。

## 4. 轨迹跟踪实验

实验现象：轨迹跟踪比连续追多个目标点更复杂。即使目标点序列是连续的，如果初始点没有对齐、`dt` 不合适、`inner_steps` 太少或关节速度限制太严格，实际轨迹也可能明显偏离期望轨迹。

解释：轨迹跟踪不仅关心当前位置误差，还关心期望轨迹在每个时刻的速度。当前项目中的 resolved-rate 控制先生成末端速度命令，再通过阻尼雅可比伪逆转换成关节速度。P+前馈控制利用了期望速度，因此在当前简化运动学模型中表现较稳定。PD 中的速度误差项依赖离散速度估计，估计噪声或参数不合适时，不一定总比 P+前馈更好。

项目结论：轨迹跟踪要同时检查路径图、误差曲线、关节角曲线和速度限制。对于入门阶段，P+前馈是一个比较容易解释且效果稳定的基准控制器。

## 5. 关节空间轨迹 vs 笛卡尔空间轨迹

实验现象：关节空间插值通常能得到更平滑的关节角、速度和加速度曲线，但末端路径不一定严格沿直线。笛卡尔空间轨迹可以更直接控制末端路径形状，但对应到关节空间后，速度和加速度可能更复杂。

解释：关节空间轨迹直接规划 `theta1`、`theta2`，所以关节层面更容易平滑。笛卡尔空间轨迹先规定末端 `x/y` 路径，再通过逆运动学或跟踪控制转成关节运动，这个映射可能放大某些关节变化。

项目结论：两种轨迹没有绝对优劣。关节空间更适合保证关节运动平滑，笛卡尔空间更适合控制末端路径形状。实际使用时要同时看末端路径和关节速度、加速度。

## 6. total_time 与轨迹重定时

实验现象：同一路径在更长的 `total_time` 下执行时，最大关节速度和最大关节加速度通常会下降，约束 violation 数量也可能减少。

解释：路径形状决定“走哪里”，时间分配决定“走多快”。当路径点不变但总时间增加时，相邻时间点之间允许的运动更慢，速度和加速度压力会降低。

项目结论：轨迹可执行性不仅由路径形状决定，也由时间参数决定。`total_time` 是连接“规划出来的路径”和“机械臂可能执行的运动”的重要参数。

## 7. 当前项目边界

当前项目仍然是 2D 二连杆机械臂的运动学层面实验，没有包含动力学、力矩、电机、摩擦、接触、传感器噪声和真实机器人控制。

这些实验适合作为机器人算法入门理解：帮助学习正/逆运动学、雅可比控制、阻尼伪逆、轨迹跟踪、轨迹空间对比和速度/加速度约束分析。它们不应被夸大为真实机械臂系统验证。

## 8. 可写进 README / 简历的结论

- 搭建了一个可运行、可测试、可画图的 2D 二连杆机械臂运动学控制实验项目。
- 实现并对比了解析逆运动学、雅可比伪逆迭代控制和阻尼最小二乘控制。
- 通过参数扫描观察了 `gain`、`max_step`、`damping` 对收敛速度、平滑性和奇异位形稳定性的影响。
- 实现 resolved-rate 轨迹跟踪，并对比 P、P+前馈和 PD 控制在简化运动学模型下的表现。
- 对比关节空间轨迹与笛卡尔空间轨迹，并用速度、加速度和 violation 指标分析轨迹可执行性。
