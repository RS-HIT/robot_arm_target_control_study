# 代码阅读笔记

建议按下面顺序阅读代码，不要一开始就从入口脚本跳到所有细节里。

## 1. `kinematics.py`

这个文件回答“机械臂几何关系是什么”。

- `forward_kinematics`：输入两个关节角和两根连杆长度，输出基座、肘关节、末端点坐标。
- `compute_jacobian`：输入当前关节角，输出雅可比矩阵。

阅读重点：

- 末端坐标由两段连杆向量相加得到。
- 第二根连杆的绝对角度是 `theta1 + theta2`。
- 雅可比矩阵描述“关节角小变化”和“末端位置小变化”的关系。

## 2. `controller.py`

这个文件回答“为了靠近目标，关节角下一步怎么变”。

- `compute_control_step`：计算末端误差，再用雅可比伪逆得到关节角更新量。
- `limit_joint_step`：限制单步更新幅度，避免数值跳变。

阅读重点：

- `error_vector = target - end_effector` 表示末端应该移动的方向。
- `np.linalg.pinv(jacobian)` 是雅可比伪逆。
- `gain` 是控制增益，决定每一步走得多积极。

## 3. `simulation.py`

这个文件回答“控制过程如何一轮一轮跑起来”。

- `run_reach_simulation`：完整仿真循环。
- `create_empty_history`：创建历史记录。
- `record_history`：保存每一步的角度、末端位置和误差。

阅读重点：

- 每轮循环先算当前末端位置。
- 再判断误差是否已经足够小。
- 如果还没到，就调用控制器更新关节角。

## 4. `plotting.py`

这个文件回答“如何把结果画出来”。

- `plot_arm_pose`：画最终机械臂姿态。
- `plot_error_curve`：画误差曲线。
- `plot_joint_curve`：画关节角变化曲线。
- `save_all_plots`：统一保存三张图。

阅读重点：

- 姿态图用三点连线表示两根连杆。
- 误差曲线应该整体下降。
- 关节角曲线展示控制过程中两个关节如何变化。

## 5. `scripts/run_reach_demo.py`

这个文件是用户入口。

它做四件事：

1. 读取命令行目标点。
2. 调用仿真函数。
3. 保存三张图片。
4. 打印最终结果。

如果你面试时介绍项目，可以按这个顺序讲：

```text
命令行输入目标点
-> 正运动学计算末端位置
-> 末端误差驱动雅可比伪逆控制
-> 迭代更新关节角
-> 输出姿态图和曲线
```
