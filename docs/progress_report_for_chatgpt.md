# robot_arm_target_control_study 阶段性进展汇报

## 项目基本信息

- 项目名称：`robot_arm_target_control_study`
- 项目定位：面向机械/机器人方向研究生的第一个小型机器人算法学习项目。
- 当前主题：二维平面二连杆机械臂目标点控制仿真。
- 当前实现方式：使用 Python、NumPy、Matplotlib 和 pytest，不依赖 ROS、MuJoCo、PyBullet 或强化学习框架。
- 当前学习重点：运动学、雅可比矩阵、雅可比伪逆控制、仿真循环、误差收敛、数据记录和结果可视化。

这个项目目前不是为了追求复杂工程，而是为了先建立机器人算法学习中的基础能力：能看懂机械臂几何关系，能写出可运行的控制循环，能记录误差变化，并能用图像解释算法结果。

## 当前阶段目标

当前阶段目标是完成一个简单、可运行、可解释、可调参数的二维二连杆机械臂目标点控制 demo。

具体来说，用户输入一个二维目标点 `target = (x, y)`，程序从初始关节角出发，反复计算机械臂末端位置和目标点之间的误差，再使用雅可比伪逆方法计算关节角更新量，让末端逐步靠近目标点。

当前阶段只关注：

- 二维平面机械臂；
- 两个转动关节；
- 末端位置目标点控制；
- 简单迭代式数值控制；
- 误差、关节角、最终姿态的记录和可视化。

当前阶段暂不关注：

- 三维机械臂；
- 动力学建模；
- 碰撞检测和避障；
- ROS / MuJoCo / PyBullet；
- 强化学习；
- 真实机器人部署。

## 已完成的核心功能

## 核心代码文件说明

### `src/robot_arm_target_control_study/kinematics.py`

这个文件负责机械臂的几何计算。

- `forward_kinematics(theta1, theta2, link1, link2)`：输入两个关节角和两根连杆长度，输出基座、肘关节、末端点三个二维坐标。
- `compute_jacobian(theta1, theta2, link1, link2)`：计算末端位置对关节角的雅可比矩阵。

它回答的问题是：

> 当前关节角是多少时，机械臂末端在哪里？如果关节角稍微变一点，末端大概会怎么动？

### `src/robot_arm_target_control_study/controller.py`

这个文件负责目标点控制中“下一步关节角怎么改”。

- `compute_control_step(...)`：计算末端误差，使用雅可比伪逆求关节角更新量，并返回 `delta_theta`、误差向量和误差大小。
- `limit_joint_step(delta_theta, max_step)`：限制单步关节角更新幅度。

其中关键关系是：

```text
Δx ≈ J Δθ
Δθ ≈ J⁺ Δx
```

这里 `J⁺` 表示雅可比矩阵的伪逆。

### `src/robot_arm_target_control_study/simulation.py`

这个文件负责把控制过程循环运行起来。

- `run_reach_simulation(...)`：运行完整目标点追踪仿真。
- `create_empty_history()`：创建用于保存历史数据的字典。
- `record_history(...)`：把当前关节角、末端位置和误差保存到历史记录中。

它回答的问题是：

> 从初始关节角出发，机械臂如何一步一步向目标点靠近？每一步的误差如何变化？

### `src/robot_arm_target_control_study/plotting.py`

这个文件负责把仿真结果画出来。

- `configure_chinese_font()`：尝试配置中文字体。

- `plot_joint_curve(...)`：画两个关节角随迭代次数变化的曲线。
- `save_all_plots(...)`：统一保存三张图片。

### `scripts/run_reach_demo.py`

## 关键算法与数据流

当前项目的数据流可以理解为下面这条链：

```text
target
-> theta
-> forward_kinematics
-> end_effector
-> error
-> J
-> J+
-> delta_theta
-> limit delta_theta
-> update theta
-> history
-> plots
```

更具体地说：

1. 用户输入目标点 `target`，例如 `(1.2, 0.6)`。
2. 程序设置当前关节角 `theta`，默认初始值为 `(0.3, 0.3)`。
3. 正运动学函数 `forward_kinematics` 根据当前 `theta` 计算机械臂末端位置 `end_effector`。
4. 程序计算误差向量 `error = target - end_effector`。
5. 程序计算误差大小，也就是末端距离目标点的欧氏距离。
6. 如果误差小于 `tolerance`，认为机械臂已经到达目标附近。
7. 如果误差还比较大，就计算当前姿态下的雅可比矩阵 `J`。
8. 使用雅可比伪逆 `J+` 把末端误差近似转换成关节角更新量 `delta_theta`。
9. 使用 `max_step` 限制 `delta_theta`，避免单步角度变化过大。
10. 更新关节角：`theta = theta + delta_theta`。
11. 把当前关节角、末端位置和误差写入 `history`。
12. 重复迭代，直到误差足够小，或者达到最大迭代次数。
13. 最后根据 `history` 和最终姿态生成图片。

## 关键数学关系

### 正运动学公式的作用

正运动学回答的是：

> 已知关节角和连杆长度，机械臂末端在哪里？

对于二维二连杆机械臂：

- 第一根连杆末端，也就是肘关节位置，由 `theta1` 和 `link1` 决定。
- 第二根连杆的绝对方向是 `theta1 + theta2`。
- 末端执行器的位置等于第一根连杆向量加上第二根连杆向量。

### 雅可比矩阵为什么是局部线性近似

机械臂末端位置和关节角之间的关系是非线性的，因为里面有 `sin` 和 `cos`。

但在当前姿态附近，如果关节角只变化很小一点，可以近似认为：

```text
末端位置小变化 ≈ 雅可比矩阵 × 关节角小变化
```

这就是雅可比矩阵的意义。它不是全局精确公式，而是当前姿态附近的局部线性近似。

### 伪逆矩阵在目标点控制中的作用

目标点控制时，我们知道“末端还差多少”，也就是末端误差 `error`。但控制器真正能直接改变的是两个关节角。

雅可比矩阵本来描述：

```text
关节角变化 -> 末端位置变化
```

伪逆矩阵则用于近似反过来求：

```text
末端希望移动的方向 -> 关节角应该怎么变
```

所以当前代码使用：

```text
delta_theta = gain * pinv(J) * error
```

### 为什么需要 `gain` 和 `max_step`

`gain` 是控制增益，决定每一步朝目标走得多积极。

- `gain` 太小：收敛可能比较慢。
- `gain` 太大：可能出现震荡或不稳定。

`max_step` 是单步关节角更新限制。

- 如果不限制单步更新，伪逆计算出的角度变化可能过大。
- 角度跳变太大时，局部线性近似容易失效，仿真可能震荡或表现不稳定。

### 为什么误差通常不能一步到位

因为雅可比矩阵只描述当前姿态附近的小范围近似，而机械臂真实运动学是非线性的。

所以控制器通常不会一次就把末端移动到目标点，而是每一步移动一点，重新计算当前姿态、误差和雅可比矩阵，再继续下一步。这个过程更像“边走边修正”。
