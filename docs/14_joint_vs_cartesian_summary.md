# 关节空间轨迹与笛卡尔空间轨迹对比总结

## 1. 关节空间轨迹的优点

- 直接规划 `theta1`、`theta2`。
- 关节角变化更容易做得平滑。
- 速度和加速度约束更容易检查。
- 适合不强制要求末端走精确路径的任务。

## 2. 关节空间轨迹的缺点

- 末端路径由正运动学间接决定。
- 即使关节角插值很平滑，末端也不一定走直线。
- 对需要严格末端路径的任务不够直观。

## 3. 笛卡尔空间轨迹的优点

- 直接规划末端 `x/y` 路径。
- 末端路径直观，容易指定直线、圆形或其他形状。
- 适合末端工具必须沿指定路径运动的任务。

## 4. 笛卡尔空间轨迹的缺点

- 需要通过逆运动学或雅可比控制转成关节运动。
- 关节速度和加速度可能波动更大。
- 接近奇异位形时更容易出现数值问题。

## 5. 什么任务适合关节空间轨迹

- 从一个姿态平滑移动到另一个姿态。
- 不要求末端严格沿直线。
- 更关心关节运动平滑、安全和容易执行。

例如：机械臂从待机姿态移动到准备姿态。

## 6. 什么任务适合笛卡尔空间轨迹

- 末端必须沿指定路径运动。
- 工具路径很重要。
- 希望直接控制末端在工作空间中的形状。

例如：画线、焊接、喷涂、擦拭、沿边缘移动。

## 7. 为什么高级机器人规划需要同时考虑末端路径和关节约束

只看末端路径，可能得到关节速度或加速度过大的轨迹。

只看关节平滑，末端可能偏离任务需要的路径。

更完整的机器人规划通常要同时考虑：

- 末端路径误差。
- 关节角限制。
- 关节速度限制。
- 关节加速度限制。
- 奇异位形。
- 碰撞和工作空间边界。

本项目第六阶段先用 2D 二连杆机械臂建立这些概念，不进入复杂动力学和真实机器人系统。
