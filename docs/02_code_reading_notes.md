# 代码阅读笔记：项目数据流

这份笔记适合在读完整体代码前快速建立项目运行流程的概念。

## 1. 总体数据流

```text
命令行输入目标点
-> 控制器迭代
-> 正运动学计算末端位置
-> 记录误差
-> 输出图像
```

对应到代码中：

- `scripts/run_reach_demo.py`：读取 `--target_x` 和 `--target_y`，把用户输入转换成目标点。
- `simulation.py`：运行迭代循环，保存每一步的关节角、末端位置和误差。
- `kinematics.py`：用正运动学计算当前机械臂的基座、肘关节和末端位置。
- `controller.py`：用雅可比伪逆根据末端误差计算关节角更新量。
- `plotting.py`：把最终姿态、误差曲线和关节角曲线保存为图片。

## 2. 一次迭代里发生什么

每一轮仿真主要做五件事：

1. 根据当前 `theta1`、`theta2` 调用正运动学，得到末端位置。
2. 计算目标点和末端点之间的误差。
3. 把当前关节角、末端位置和误差记录到 `history`。
4. 如果误差小于阈值，就认为已经到达目标附近。
5. 如果还没到，就用雅可比伪逆计算关节角更新量，并进入下一轮。

## 3. 推荐阅读顺序

建议按下面顺序读：

1. `scripts/run_reach_demo.py`：先看用户入口。
2. `src/robot_arm_target_control_study/simulation.py`：理解主循环。
3. `src/robot_arm_target_control_study/kinematics.py`：理解正运动学和雅可比矩阵。
4. `src/robot_arm_target_control_study/controller.py`：理解雅可比伪逆控制。
5. `src/robot_arm_target_control_study/plotting.py`：理解结果如何输出。

## 4. 解析逆运动学的数据流

解析逆运动学是一种“直接求解”方法。它不需要一步一步迭代，而是直接根据目标点和两根连杆长度算出关节角。

```text
目标点
-> 判断可达性
-> 余弦定理求 theta2
-> 几何关系求 theta1
-> 正运动学验证
```

对应到代码中：

- `is_target_reachable()`：先判断目标点离基座是不是太远或太近。
- `inverse_kinematics_analytic()`：用余弦定理求第二个关节角，再用三角关系求第一个关节角。
- `forward_kinematics()`：把算出的关节角代回去，验证末端是否真的到达目标点。

## 5. 雅可比伪逆控制的数据流

雅可比伪逆控制是一种“迭代逼近”方法。它每次只让关节角改变一小步，重复多次后让末端逐渐靠近目标点。

```text
目标点
-> 当前末端位置
-> 末端误差
-> 雅可比矩阵
-> 伪逆求关节角增量
-> 更新关节角
-> 重复迭代
```

对应到代码中：

- `run_reach_simulation()`：负责循环，每轮计算末端位置、误差，并决定是否停止。
- `compute_control_step()`：用雅可比伪逆把末端误差转换成关节角增量。
- `compute_jacobian()`：描述当前姿态下，关节角变化会怎样影响末端位置。

## 6. 两种方法的区别

- 解析逆运动学是一种“直接求解”。
- 雅可比伪逆是一种“迭代逼近”。
- 解析法适合结构简单、自由度较少的机械臂。
- 雅可比法更容易推广到高自由度和复杂机械臂，但可能受初始值、步长、奇异位形影响。

可以用下面命令观察两种方法的输出差异：

```bash
python scripts/run_compare_methods.py --target_x 1.2 --target_y 0.6
```
