# PD 控制学习笔记

## 1. P 项是什么

P 项是比例项，意思是根据当前误差大小直接给出修正。

在本项目中，误差是：

```text
error = desired_xy - current_xy
```

P 项可以理解为：

```text
p_term = kp * error
```

误差越大，修正越大；误差越小，修正越小。

## 2. D 项是什么

D 项是微分项，关注误差变化速度。

在早期简化写法中，可以用相邻两步误差做近似：

```text
error_derivative = (error - prev_error) / dt
d_term = kd * error_derivative
```

它不只看“现在差多少”，还看“误差正在怎么变”。

不过在轨迹跟踪里，离散目标点本身也在移动，直接用 `error_derivative` 容易产生 derivative kick。当前项目的 resolved-rate PD 默认改用速度误差：

```text
velocity_error = desired_velocity - actual_velocity
```

也就是比较“希望末端怎么动”和“实际末端怎么动”。

## 3. 为什么 D 项可以抑制震荡

如果误差变化很快，说明系统可能正在快速冲向目标或冲过目标。D 项会根据误差变化速度给出额外修正，让控制不那么猛。

直觉上，D 项像是在提醒控制器：

```text
不要只看离目标多远，也要看自己是不是冲得太快。
```

## 4. D 项和阻尼最小二乘中的 damping 有什么区别

D 项来自控制误差的变化速度，关注的是时间上的变化趋势。

阻尼最小二乘中的 `damping` 是加在雅可比矩阵求解里的数值阻尼，关注的是矩阵接近奇异时不要把关节角更新放得太大。

简单区分：

- D 项：控制层面的“看误差变化速度”。
- damping：矩阵求解层面的“数值刹车”。

它们都可能让系统更稳，但不是同一个东西。

## 5. 为什么 I 项暂时不加入

I 项会累计长期误差，常用于处理稳态误差。但它也会带来积分累积、过冲和更多调参问题。

当前项目还处在运动学控制学习阶段，先理解 P 和 D 更合适。

## 6. 什么时候才需要 PID

当系统存在长期偏差，例如摩擦、重力、外部扰动、执行器误差导致一直到不了目标时，I 项可能有帮助。

真实机器人控制、速度控制、电机控制中经常会用 PID 或它的变体。但是否需要 I 项，要看系统误差来源和控制目标。

## 7. 本项目中的 PD 是简化任务空间 PD，不是完整动力学控制

本项目中的 PD 控制只在末端位置空间中生成一个修正命令，再通过雅可比伪逆换算成关节角变化。

它没有考虑：

- 连杆质量。
- 转动惯量。
- 关节力矩。
- 摩擦。
- 电机响应。

所以它适合用来理解 PD 思想，但还不是完整机器人动力学控制。

## 8. 如何调试 PD 参数

建议先用：

```bash
python scripts/run_trajectory_tracking_demo.py --trajectory line --controller p_ff
```

确认轨迹生成、IK 起点初始化和速度前馈都正常。`p_ff` 稳定后，再测试：

```bash
python scripts/run_trajectory_tracking_demo.py --trajectory line --controller pd --kd 0.02
```

`kd` 建议从 `0.0`、`0.02`、`0.05`、`0.1` 逐步尝试。

- 如果关节角曲线出现高频锯齿，说明 `kd` 可能过大，或者实际速度估计太敏感。
- 如果误差曲线变得更平滑，说明 `kd` 可能起到了抑制震荡的作用。
- 如果 `pd` 比 `p_ff` 更差，不代表 PD 概念错误，可能是当前简化运动学模型中速度估计不稳定。
